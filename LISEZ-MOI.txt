XerviX v6 — paquet PWA (tests)

Contenu : index.html (l'app complète), manifest.json, sw.js, icônes.

Pour installer sur téléphone, il faut servir ce dossier en HTTPS
(un service worker ne fonctionne pas depuis un fichier local) :

1. Le plus simple : déposer le dossier sur Netlify Drop
   (https://app.netlify.com/drop) ou le pousser sur GitHub Pages.
2. Ouvrir l'URL obtenue sur le téléphone.
3. Android/Chrome : menu ⋮ → « Installer l'application ».
   iOS/Safari : Partager → « Sur l'écran d'accueil ».

En local sur ordinateur : python3 -m http.server 8080
puis http://localhost:8080 (localhost est autorisé).

Sans serveur, index.html s'ouvre quand même en double-cliquant :
l'app fonctionne, seule l'installation hors ligne est indisponible.
